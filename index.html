Method

1. Site and pixel selection

Points are drawn from a classified mangrove map of the Sisal AOI, combining the Global Mangrove Watch product with ESA land cover data. Random point coordinates are fixed in a CSV so repeat runs use the same points. Points are split between anthropogenic and unmodified areas, and between water-associated and land locations, for direct comparison.

2. Data extraction

Landsat imagery is filtered by a cloud cover threshold and the study time range. Maximum NDVI per interval is extracted for each coordinate. ERA5 climatology (temperature, precipitation, salinity where applicable, evapotranspiration/evaporation) is extracted for the same coordinates.

3. Processing and analysis

Five metrics are computed on the NDVI series: standard deviation, AR1, return rate, kurtosis, and skewness. Kendall's tau is computed on the trend of each metric, and separately on the trend of NDVI itself. Breakpoint detection (LandTrendr) is cross-checked against visual inspection of the NDVI curve.

4. Land versus water points

Salinity applies only to water-associated points. Land points show evapotranspiration rather than evaporation, since they are vegetated rather than open water or wet soil. The scenario classification below applies to water-associated wetland points; land points are treated as converted or reference locations rather than fitted to the tipping-point framework.

5. How we classify tipping-point status

Each water-associated point is classified by crossing the trend of NDVI itself against the trend of NDVI's standard deviation, both tested with Kendall's tau. A rising standard deviation paired with falling NDVI is the classic early-warning signature: variance rises before a system crosses a threshold. LandTrendr's breakpoint detection and a visual check of the curve confirm or refine which scenario applies.

7. Do it yourself in Google Earth Engine

Run this same analysis on your own coordinate. The steps below match the pipeline above; the script covers steps 1–4.

// Sisal mangrove NDVI extraction — starter script
// 1. Define your point (swap in your own coordinates)
var point = ee.Geometry.Point([-90.033, 21.161]);

// 2. Build a cloud-masked Landsat surface reflectance collection, 1984-present
function maskClouds(img) {
  var qa = img.select('QA_PIXEL');
  var cloud = qa.bitwiseAnd(1 << 3).eq(0).and(qa.bitwiseAnd(1 << 4).eq(0));
  return img.updateMask(cloud);
}

var landsat = ee.ImageCollection('LANDSAT/LC08/C02/T1_L2')
  .merge(ee.ImageCollection('LANDSAT/LE07/C02/T1_L2'))
  .merge(ee.ImageCollection('LANDSAT/LT05/C02/T1_L2'))
  .filterBounds(point)
  .filterDate('1984-01-01', '2026-12-31')
  .map(maskClouds);

// 3. Compute NDVI per image (band names vary slightly by sensor)
function addNDVI(img) {
  var ndvi = img.normalizedDifference(['SR_B5', 'SR_B4']).rename('NDVI');
  return img.addBands(ndvi);
}
var withNDVI = landsat.map(addNDVI);

// 4. Extract the NDVI time series at the point and export to CSV
var series = withNDVI.select('NDVI').getRegion(point, 30);

Export.table.toDrive({
  collection: ee.FeatureCollection(
    ee.List(series).slice(1).map(function (row) {
      row = ee.List(row);
      return ee.Feature(null, { date: row.get(3), ndvi: row.get(4) });
    })
  ),
  description: 'sisal_point_ndvi',
  fileFormat: 'CSV'
});
