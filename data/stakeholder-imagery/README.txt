Yearly satellite snapshots for the Stakeholder page (pipeline output, do not edit by hand).

- One image per year, named by the year: 1984.jpg, 1985.jpg, ... 2026.jpg
  (the file type is set by "extension" in content/stakeholders.json).
- All images must have exactly the same extent and crop, so the stakeholder areas line up.
- If the image of a year is missing, the site shows the placeholder image
  (img/stakeholder-map-placeholder.jpg) and says so in the imagery label on the map.
